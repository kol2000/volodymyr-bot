# Чтение ссылок

`link_reader.py` читает публичные HTTPS-страницы по `/read URL`, обращению «бубус перескажи URL» или ответу на сообщение со ссылкой. Поддерживает Telegram text_link. До двух ссылок за запрос; обычные ссылки без обращения не вызывают автоматический ответ.

HTML очищается от меню/скриптов, предпочтение article/main. До 1 МБ загрузки, 15 секунд на страницу; длинный текст сокращается с отметкой. Основная модель объясняет публикацию в своей манере. Ссылки и дата из метаданных сохраняются. Пересказ не объявляется проверкой истинности; существующий fact_check сохраняет отдельный whitelist.

Уточнения ответом на пересказ используют прочитанный текст: таблица link_reads, область chat_id/message_id, TTL 24 часа, максимум 50 записей на чат. Очистка при следующей записи. Это публичный текст; приватные страницы/авторизация не поддерживаются. PDF, видео, страницы только с JS и платный доступ могут не читаться. Отказ честный, без пересказа заголовка вместо статьи.

Защита: только HTTPS/443, без credentials, проверка всех DNS IP и каждого redirect, TLS к проверенному IP с исходным hostname. Произвольные адреса не отправляются через внешний proxy. Текст страницы считается данными, а не инструкциями модели. При недоступности прямой сети чтение может отказать; не ослаблять SSRF-защиту ради proxy.

Проверка: `PYTHONPATH=.:tests python3 -B -m unittest test_link_reader test_fact_check`. Тесты не отправляют сообщения. Новый импорт требует перезапуска volodymyr-bot. Пользовательские ссылки и содержание кэша не публиковать в Git.
