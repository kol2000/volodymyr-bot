# Развлекательные рубрики Бубуса

`chat_features.py` — отдельные процессы; основной бот не нужно перезапускать.

- `bubus-chat-awards.timer`: воскресенье 21:00 Europe/Moscow. Период от предыдущего воскресенья 21:00 до текущего; вечер после выпуска попадает в следующую премию. Первый выпуск 29.11.2026.
- `bubus-chat-memory.timer`: каждый день 12:00 МСК. Без записи на точную дату из предыдущих лет ничего не отправляет. 29 февраля не переносится на 28-е. Пропущенные дни не рассылаются пачкой.
- Установка: `sudo bash /home/botadmin/volodymyr_bot/install_chat_features.sh`. Старые прогнозные таймеры не меняются.
- Предпросмотр: `python3 -B chat_features.py awards --with-model` или `memory`. `--check` печатает только наличие и размер текста. Отправка требует `--send`.

Источники: `chat_archive` в state/bot.sqlite3 (только привязанный чат), salary_votes и общий журнал football_forecasts. install создаёт таблицу и триггеры INSERT/UPDATE на messages, переносит сохранившиеся сообщения. Удаление краткосрочного контекста не удаляет архив; личные диалоги не архивируются. Архив сохраняется бессрочно для рубрики; при запросе удаления сообщений очищать и эту таблицу. Данные не коммитить. До первой установки сделана закрытая резервная копия SQLite в state/maintenance_backups.

Флудер — число сохранённых текстовых сообщений. Фраза — повторяющаяся тройка слов минимум в трёх сообщениях. Тема — частое ключевое слово (это явно подписано). Спор — самая длинная цепочка ответов разных авторов, не оценка их враждебности. Для смешной реплики используются ответы со смехом разных участников; при их отсутствии существующая модель выбирает ID из равномерной выборки до 120 сообщений. Цитата также выбирается по ID. Текст и автор берутся из базы, HTML экранируется. Ошибка модели не блокирует остальные номинации.

Ответ Бубуса выбирается по положительным оценкам/смешливым ответам. Показывается изменение виртуальной зарплаты за период (80 грн за плюс/минус), баланс не изменяется. Футбольная номинация — подтверждённый точный прогноз самого Бубуса из нового журнала за 90 минут; прогнозы участников не приписываются и задним числом не реконструируются. При нескольких точных попаданиях выбирается первое по началу матча.

«В этот день» использует точные даты долгосрочного архива и data/examples.jsonl с собственными репликами Бубуса начиная с 2020 года. Старый корпус не содержит chat_id/авторов контекста: цитируется только text как реплика Бубуса, без выдуманных ссылок и без приписывания контекста участникам. Если кандидатов несколько, выбирается наиболее свежий год и длинная содержательная реплика. Автоматического выдуманного пересказа старых событий нет.

Отправка через существующий Telegram-клиент в текущий settings.chat_id. Журнал `state/chat_features/<chat>/<kind>/weekly_reports/<date>/`: attempt.json до отправки, sent.json после подтверждения, uncertain.json при сбое. Любой attempt блокирует повтор; перед ручным восстановлением сверить Telegram, не удалять вслепую. Используется общий guard forecast_weekly.publish.

Проверки: `PYTHONPATH=.:tests python3 -B -m unittest test_chat_features test_forecast_weekly` (11 тестов: границы, изоляция чатов, архив после очистки, исправления, реальные ID, зарплата, точные даты, високосность, повторная/неопределённая отправка).
