# Зрение Бубуса

visual_context.py: Telegram getFile → ограниченное скачивание → JPEG/кадры → gemma3:4b → текстовое описание → основная config.model с prompt.txt. Текстовая модель сохраняет характер. Дополнительный Tesseract rus+eng передаёт независимое OCR-чтение текста обеим моделям. Никаких новых внешних провайдеров: используется существующий config.ollama_url; установленная Gemma объявляет capability vision.

В группе: картинка с обращением «бубус…»/упоминанием, вопрос о картинке, ответ-вопрос на изображение, либо стикер в ответ на сообщение Бубуса. В личке доступ прежний — владелец. Не анализирует все изображения группы самовольно. Фото без подписи сохраняется в контексте маркером, чтобы не теряться до маршрутизации. /bubus с изображением поддерживается.

Форматы: Telegram photo, JPEG/PNG/WebP/GIF как document, статический WebP-стикер, WebM-видеостикер, animation. Видео: до трёх кадров с частотой 1 fps. GIF пока первый кадр. TGS: только Telegram thumbnail, без разбора движения; ограничение указано в ответе. Без превью честный отказ. PDF не поддерживается.

Лимиты: 12 MiB скачивания, 24 млн пикселей, максимум 1600 px после нормализации. Pillow и ffmpeg уже есть на ВМ. EXIF-поворот учитывается; прозрачность на белом фоне. Временные видео/кадры удаляются. URL с токеном не логируется. Сырые изображения не сохраняются в историю/репозиторий; обычный ответ сохраняется штатно.

vision_model необязательный ключ config.json (по умолчанию gemma3:4b); vision_url необязательный полный адрес /api/chat (по умолчанию существующий ollama_url + /api/chat). Модель получает описание как недоверенные данные; команды внутри картинки не считаются инструкциями. Чтение чисел/текста может ошибаться, модель должна отмечать неопределённость.

Обработка в существующей очереди utility, сетевой анализ не выполняется в Telegram polling. Срок задания 360 секунд, таймаут каждой модели 90 секунд. Сохраняются существующие ограничения частоты/отправки/смены чата. При ошибке понятная реплика, не выдуманное описание. Бот не заменяет визуальный ответ случайным стикером.

Проверки: PYTHONPATH=.:tests python3 -B -m unittest test_visual_context test_prediction_buttons.ButtonTests (13). Есть тест без подписи, обращение по имени, ответ на изображение, отсутствие обращения, ограничения размера, две разные модели и TGS-превью. Реальный WebM проверен: три кадра. До активации нужен перезапуск volodymyr-bot.

Итоговая адресная проверка на ВМ: 24 теста (visual_context, prediction_buttons, forecast_weekly, chat_features). Реальная цепочка Gemma → Qwen запущена на синтетическом скриншоте; после добавления OCR ответ объяснил код 404. Мелкая визуальная модель ошибается в оформлении/отдельных буквах — не считать это гарантией точного OCR или чтения сложных таблиц.
